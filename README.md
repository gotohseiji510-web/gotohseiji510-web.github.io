# gotohseiji510-web.github.io

GoogleタスクとカレンダーをClaudeから使うための、Google認証（OAuth、プロジェクト antigravity-487820）の説明ページです。

- Googleの「本番公開」には、ホームページとプライバシーポリシーのURLが必要です。このリポジトリの `index.html` と `privacy.html` がそのURLです。
- 公開のままにしてください。非公開にしたり消したりすると、ページが404になります。
- 顧客情報・パスワード・キーは入っていません。
